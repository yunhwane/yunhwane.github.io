## 블로그를 시작하게 된 계기

개발을 하면서 매일 새로운 것들을 배우지만, 시간이 지나면 잊혀지는 것들이 많았습니다. 이 블로그는 그런 지식들을 체계적으로 정리하고 공유하기 위한 공간입니다.

## 주로 다룰 주제

- **개발 경험과 회고** — 프로젝트를 진행하며 느낀 점들
- **기술 학습 노트** — 새로 배운 기술의 핵심 정리
- **문제 해결 과정** — 삽질의 기록과 해결 방법

## 기술 스택

```java
public class Blog {
    private final String author = "yunhwane";
    private final List<String> interests = List.of(
        "Backend", "Spring", "JPA", "Architecture"
    );
}
```

> 좋은 개발자는 코드를 작성하는 사람이 아니라, 문제를 해결하는 사람이다.

꾸준히 기록해 나가겠습니다.
